名店検索ツール

評判は良いのに公式ホームページがないお店を探します。検索はあなた自身のGoogle APIキーでブラウザから直接行われ、料金もあなた自身のGoogleアカウントに課金されます（このサイトの運営者には一切課金されません）。

①Google APIキーを設定する（初回のみ）
ここに入力したキーは、あなたのブラウザだけに保存され（localStorage）、このサイトのサーバーには一切送信されません。検索は、あなたのブラウザから直接Googleへ問い合わせるため、料金もあなたのGoogleアカウントに課金されます。
キーの取得方法は下の「APIキーの取得方法」を開いてください。取得したら、必ずGoogle Cloud Consoleで「HTTPリファラー」による制限をかけてください（このページのURLを許可リストに入れる）。制限をかけないと、他人にキーを見られたときに勝手に使われる恐れがあります。
APIキーの取得方法

1. Google Places APIキー（必須）

  1. Google Cloud Console を開き、Googleアカウントでログイン
  2. 新しいプロジェクトを作成
  3. 「APIとサービス」→「ライブラリ」で「Maps JavaScript API」と「Places API (New)」の両方を検索して有効化
  4. 「お支払い」で請求先アカウント（クレジットカード）を設定（無料枠がありますが設定自体は必要です）
  5. 「認証情報」→「認証情報を作成」→「APIキー」でキーを発行
  6. 発行したキーの「アプリケーションの制限」を「HTTPリファラー（ウェブサイト）」にし、このページのURLを登録（重要・安全のため）

2. Googleカスタム検索API（任意。SNS確認・キーワード検出に使用）

  1. Programmable Search Engine で新しい検索エンジンを作成し、検索対象を「ウェブ全体」に設定 → 「検索エンジンID」をコピー
  2. Google Cloud Consoleの「ライブラリ」で「Custom Search API」を有効化し、APIキーを発行
  3. 無料枠は1日100クエリまでです
1回の調査に数十秒〜1分ほどかかります。APIキー未設定でもデモ動作を確認できます。
評価・口コミ数はGoogleマップの検索時点の情報です。「確認できず」は裏付けが取れなかった項目です。営業前に必ず最新情報をご確認ください。
「選出理由」は、取得した数値やキーワードの有無だけを機械的に並べたものです（AIによる文章生成は行っていません）。公式サイトの技術診断のみ、このサイトのサーバーで実施しています（Google APIは使っていません）。
